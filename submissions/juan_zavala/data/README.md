# Data

`big_nss.csv` is not committed because it is 85 MB. Download it from the course's Google Drive folder (the link is in the repository's main README) and save it in this folder as `data/big_nss.csv`.

To confirm you have the same file the notebook was run on:

| Check | Expected |
|---|---|
| Size | 85,152,735 bytes |
| Rows | 1,187,335, plus a header line |
| MD5 | `32170d026644c1ba9fe1be196c459f74` |

On a Mac, `md5 data/big_nss.csv` prints the checksum.
